Bubbscord

Плагин для Vencord, который делает Discord округлым и похожим на Telegram: капсулы и «таблетки» вместо квадратов, сообщения пузырями, твои — справа, свои цвета и обои. Заодно разгружает Discord: ставит гифки на паузу в фоне и убирает лишние кнопки.

Где взять

Bubbscord раздаётся архивом Bubbscord.zip на Discord-сервере автора.

  1. Скачай Bubbscord.zip с сервера автора: нажми на файл в сообщении → Скачать.
  2. Распакуй: ПКМ по архиву → Извлечь всё. Внутри будут: bubbscord — папка плагина Bubbscord.theme.css — тема Инструкция.html — эта страница
  3. Выбери способ ниже — тему или плагин.

Тема или плагин

Есть два способа поставить Bubbscord. Тема ставится за минуту, плагин даёт всё, но его нужно собрать. Выбери один.

Не включай тему и плагин одновременно — стили наложатся друг на друга и всё поедет.

Установка темы

Если Vencord уже стоит (в настройках Discord есть раздел Vencord) — начинай с шага 4.

  1. Скачай официальный установщик Vencord с сайта vencord.dev/download (кнопка для Windows).
  2. Запусти его, выбери свой Discord (обычно Stable) и нажми Install.
  3. Полностью закрой Discord (значок в трее → Quit) и открой заново — в настройках появится раздел Vencord.
  4. Discord → Настройки → Vencord → Themes.
  5. Нажми Open Themes Folder — откроется папка тем.
  6. Положи туда файл Bubbscord.theme.css из архива.
  7. Вернись в Discord и включи Bubbscord Round в списке тем.

Установка плагина

Сторонние плагины Vencord ставятся только сборкой из исходников. Это делается один раз, дальше — только обновления.

Сначала установи

  1. Git — всё по умолчанию.
  2. Node.js LTS — всё по умолчанию.
  3. pnpm: открой PowerShell и выполни
    npm install -g pnpm

Потом собери Vencord с Bubbscord

  1. Открой PowerShell в папке, где будет лежать Vencord (например, на рабочем столе), и скачай исходники:
    git clone https://github.com/Vendicated/Vencord
  2. Зайди в папку и поставь зависимости:
    cd Vencord
    pnpm install --frozen-lockfile
  3. Скопируй папку bubbscord из архива в Vencord\src\userplugins\. Папки userplugins может не быть — создай её. Должно получиться Vencord\src\userplugins\bubbscord\index.tsx.
  4. Собери:
    pnpm build
  5. Установи в Discord и выбери свой Discord (обычно Stable):
    pnpm inject
  6. Полностью закрой Discord (значок в трее → Quit) и открой заново.
  7. Настройки → Vencord → Plugins → Bubbscord — включи и нажми шестерёнку: там все настройки.

Если PowerShell пишет, что pnpm не является командой — закрой и снова открой PowerShell после установки pnpm, или пиши npx pnpm вместо pnpm.

Обновление

Когда выходит новая версия, Bubbscord сам показывает уведомление «Доступно обновление» (проверка раз в сутки; вручную — кнопка «Проверить обновления» в настройках плагина). Обновиться — в PowerShell, в папке Vencord:

git -C src\userplugins\bubbscord pull; git pull; pnpm install --frozen-lockfile; pnpm build

Если ставил из архива, а не через git clone, — сначала замени папку bubbscord на новую из свежего архива, потом выполни ту же команду без первой части. После обновления полностью перезапусти Discord (трей → Quit).

Настройки

Всё находится в Настройки → Vencord → Plugins → Bubbscord (шестерёнка). Справа — значение по умолчанию.

Интерфейс

Интерфейс Bubbscordвкл Капсулы, «таблетки», скругления и плавные анимации по всему Discord. Выключишь — вернётся обычный вид, остальные функции продолжат работать.

Тема в стиле Telegram

Шрифты

ШрифтDiscord Как в Telegram — выбери шрифт из списка: Segoe UI Variable, Bahnschrift, Calibri, Candara (округлый), Verdana, Georgia (с засечками), Cascadia Code (моноширинный), Comic Sans и другие. Это шрифты из Windows — работают без интернета и не тормозят. Превью в редакторе темы сразу показывает выбранный шрифт.
Свой шрифтпусто Любой шрифт, установленный на компьютере: выбери «Свой» в списке выше и впиши точное название (например, Nunito). Шрифт ставится как обычно: скачай, ПКМ по файлу → «Установить», перезапусти Discord.
Где менять шрифтвесь Discord Во всём Discord или только в тексте сообщений и никах в чате.
Размер текста сообщений16 px От 12 до 22. 16 — как в обычном Discord.

Скорость и чистота

Пауза в фоневкл Гифки встают на паузу, когда Discord свёрнут или ты в игре, и продолжаются, когда возвращаешься.
Без размытиявкл Убирает размытие за окнами и картинками — самый тяжёлый эффект для видеокарты.
Спрятать лишнеевкл Кнопки подарка и стикеров у поля ввода, квесты и лаунчер приложений. Вкладки Nitro и Магазин остаются.
Спрятать «Сейчас активны»вкл Правая колонка на странице друзей.
Убрать украшениявкл Рамки аватаров, эффекты профилей и анимированные таблички ников — они крутятся постоянно и нагружают процессор.
Быстрый чатвыкл Сплошной тёмный фон под сообщениями: прокрутка легче, обои остаются по бокам. Для слабых компьютеров.
Без анимацийвыкл Всё реагирует мгновенно, без плавных переходов. Для слабых компьютеров.

Из Telegram

Только в плагине. Всё хранится у тебя на компьютере и никуда не отправляется — кроме текста, который ты сам решил перевести (он уходит в Google Translate).

⭐ ИзбранноеПКМ по сообщению ПКМ по сообщению → «В Избранное». Все сохранённые — по звёздочке у поля ввода: с поиском, картинками и кнопкой «Перейти» к сообщению.
⏰ НапоминанияПКМ по сообщению ПКМ по сообщению → «Напомнить» → через 20 минут, час, 3 часа, вечером в 20:00 или завтра в 9:00. В нужное время всплывёт уведомление, клик — переход к сообщению. Если Discord был закрыт, пропущенные напоминания придут сразу при запуске. Список и отмена — по звёздочке у поля ввода, вкладка «Напоминания».
⚡ Быстрые ответымолния у поля ввода Свои шаблоны текста. Клик по молнии у поля ввода — список шаблонов, выбранный вставляется в сообщение. Или команда /шаблон название — сразу отправит. Добавить и изменить — ПКМ по молнии или вкладка «Шаблоны».
🌐 ПереводПКМ по сообщению ПКМ по сообщению → «Перевести»: перевод появится прямо под сообщением. Язык перевода — в настройках, по умолчанию русский.
🖼️ Обои для чатаПКМ по чату ПКМ по ЛС, группе или каналу → «Обои этого чата» → своя картинка только для этого чата. В остальных — общие обои.
📁 Папки чатовнад списком ЛС Вкладки над списком ЛС: Все, Личные, Группы и свои. «+» — новая папка. Добавить чат в папку — ПКМ по ЛС → «Папка» → отметь нужные. ПКМ по вкладке — переименовать или удалить. Выключаются в настройках.

Свои обои

  1. Включи «Обои: своя картинка».
  2. Нажми «Выбрать обои с компьютера». Под кнопкой появится проверка размера: например, ✓ размера хватает, будет чётко или ⚠ растягивается в 2.6 раза и будет мыльной.
  3. Подстрой ползунки под картинку.
Затемнение обоев70 % Чтобы текст читался. Меньше — картинка ярче.
Тень на боковых панелях40 % 0 — колонки полностью прозрачные.
Какую часть показыватьверх Если картинка не влезает целиком: верх (лица не обрезаются), центр, низ, левый или правый край.
Размытие обоев0 px Мягкий фон, если картинка слишком пёстрая.
Ссылка на картинкупусто Вместо файла. Discord пускает картинки только с некоторых сайтов (i.imgur.com, i.ibb.co, i.pinimg.com, cdn.discordapp.com, files.catbox.moe, GitHub) и только прямые ссылки на саму картинку. Если не загрузится — появится уведомление.

Для чёткого фона картинка должна быть не меньше экрана: для обычного монитора — от 1920×1080. Маленькую картинку (например, превью с Pinterest на 736px) можно увеличить нейросетью в бесплатной программе Upscayl — для аниме-артов результат почти как у оригинала.

Если что-то не так

Bubbscord нет в списке плагинов

Проверь путь: должно быть Vencord\src\userplugins\bubbscord\index.tsx (а не …\bubbscord\bubbscord\…). Потом снова pnpm build и Ctrl+R в Discord.

После обновления Discord всё пропало

Discord иногда стирает Vencord при своём обновлении. В папке Vencord снова выполни pnpm inject и перезапусти Discord.

«pnpm не является командой»

Закрой и заново открой PowerShell после установки pnpm. Не помогло — пиши npx pnpm вместо pnpm.

Обои мыльные

Картинка меньше экрана, и Discord её растягивает — открой настройки Bubbscord, под кнопкой выбора обоев написано, во сколько раз. Найди картинку крупнее или увеличь её в Upscayl.

Обои по ссылке не появляются

Сайта нет в списке разрешённых Discord или это ссылка на страницу, а не на картинку. Сохрани картинку и выбери её файлом с компьютера.

Мои сообщения не уходят вправо

Должны быть включены оба пункта: «Сообщения пузырями» и «Свои сообщения справа». Плагин узнаёт твои сообщения по аватарке, а если она стандартная — по нику.

Всё выглядит «двойным» или поехало

Скорее всего, одновременно включены тема Bubbscord Round и плагин. Оставь что-то одно. Ещё проверь, не включены ли другие темы.

Честно о рисках. Любые моды клиента (Vencord, BetterDiscord и т. п.) формально нарушают правила Discord. Банов за косметику практически не бывает, но решай сам. Bubbscord — сторонний плагин: поддержка Vencord с ним не помогает, вопросы — автору, Sherry Williams.
