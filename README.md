# Bubbscord — округлый Discord в стиле Telegram

Плагин для [Vencord](https://vencord.dev): капсулы и «таблетки» вместо квадратов,
сообщения пузырями как в Telegram (свои — справа), редактор цветов и шрифтов, свои обои,
Избранное, напоминания, быстрые ответы, перевод, папки чатов — и разгрузка Discord.

## Установка в один клик

1. Скачай **[`Установить Bubbscord.bat`](https://github.com/samvelhiden-boop/Bubbscord/raw/main/%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%B8%D1%82%D1%8C%20Bubbscord.bat)**.
2. Дважды кликни по нему. Если Windows спросит «Защитила ваш компьютер» — **Подробнее → Выполнить в любом случае**.
3. Подожди 2–5 минут — установщик сам поставит всё нужное, соберёт Vencord с Bubbscord,
   установит в Discord, включит плагин и откроет Discord.

Всё. Обновления потом приходят уведомлением — нажми на него, и плагин обновится сам.
Запустить установщик ещё раз = обновить всё вручную.

Подробная инструкция со всеми настройками — в файле `Инструкция.html` (открывается в браузере).

## Способ 1. Тема (просто)

Если Vencord ещё не стоит (в настройках Discord нет раздела **Vencord**):
скачай официальный установщик с [vencord.dev/download](https://vencord.dev/download),
запусти, выбери свой Discord (обычно Stable) → **Install**, потом полностью закрой
Discord (трей → Quit) и открой заново.

1. Discord → **Настройки → Vencord → Themes** → **Open Themes Folder**.
2. Положи туда файл `Bubbscord.theme.css`.
3. Включи **Bubbscord Round** в списке тем.

## Способ 2. Плагин (полная версия)

Сторонние плагины Vencord ставятся только сборкой из исходников.
Делается один раз, дальше — обновление одной командой.

### Что нужно установить заранее
- [Git](https://git-scm.com/download/win)
- [Node.js LTS](https://nodejs.org)
- pnpm — открой PowerShell и выполни:
  ```powershell
  npm install -g pnpm
  ```

### Установка
Открой PowerShell в папке, где будет лежать Vencord (например, на рабочем столе), и выполняй по очереди:

```powershell
git clone https://github.com/Vendicated/Vencord
```
```powershell
cd Vencord
```
```powershell
pnpm install --frozen-lockfile
```
```powershell
git clone https://github.com/samvelhiden-boop/Bubbscord src\userplugins\bubbscord
```
```powershell
pnpm build
```
```powershell
pnpm inject
```

В окне `inject` выбери свой Discord (обычно Stable). Полностью закрой Discord
(значок в трее → Quit) и открой снова.

Дальше: **Настройки → Vencord → Plugins → Bubbscord** — включи и нажми шестерёнку.

> Если пишет `pnpm не является командой` — закрой и заново открой PowerShell
> после установки pnpm, или пиши `npx pnpm` вместо `pnpm`.

### Обновление
Когда вышла новая версия, Bubbscord сам покажет уведомление «Доступно обновление».
**Нажми на него** — плагин скачает новую версию, пересоберёт Vencord и предложит
перезапустить Discord. То же самое — кнопка **«Обновить сейчас»** вверху настроек плагина.
Работает и если плагин ставили из архива: при первом обновлении папка станет копией репозитория.

Если автообновление не сработало — вручную, в PowerShell, в папке `Vencord`:

```powershell
git -C src\userplugins\bubbscord pull
```
```powershell
git pull
```
```powershell
pnpm install --frozen-lockfile
```
```powershell
pnpm build
```

Потом полностью перезапусти Discord (трей → Quit).

## Честно о рисках
Любые моды клиента (Vencord, BetterDiscord и т. п.) формально нарушают правила Discord.
Банов за косметику практически не бывает, но решай сам. Это сторонний плагин —
поддержка Vencord с ним не помогает, вопросы — автору (Sherry Williams).

Всё, что сохраняет плагин (Избранное, напоминания, шаблоны, папки, обои), лежит только
на твоём компьютере. Наружу уходят только текст, который ты сам переводишь (Google Translate),
и раз в сутки — запрос номера версии с GitHub.
